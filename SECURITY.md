# Security Policy

## Supported version

Security fixes are applied to the latest commit on the default branch.

## Reporting a vulnerability

Please avoid publishing exploit details, credentials, private footage, personal paths, or sensitive media in a public issue. Open a minimal issue requesting a private contact path, and include only non-sensitive reproduction context.

Useful reports identify the affected command, expected integrity boundary, observed bypass or failure, operating system, Python version, and whether the issue can alter source media, approval receipts, vendor verification, render attribution, or QA results.
